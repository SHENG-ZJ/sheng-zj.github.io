# Zijie Sheng — Personal Website

A single-file interactive personal website for GitHub Pages. No build step, package manager, backend, or third-party assets are required.

## Publish

1. Sign in to GitHub and create a **public** repository named `YOUR_USERNAME.github.io` (replace `YOUR_USERNAME` with your exact GitHub username).
2. Upload the `index.html` and `.nojekyll` files from this folder to the **root** of the repository. Commit them to the `main` branch.
3. Open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Visit `https://YOUR_USERNAME.github.io/`. Deployment can take several minutes.

If you already have a GitHub Pages repository, simply replace the root `index.html` and commit; you do not need to create a new repo.

## Editing

- The site design, content, animation, and controls are entirely inside `index.html`.
- To edit text or email, search in `index.html` for the existing phrase or email address and replace it.
- The contact icon uses `mailto:shengzijie001@gmail.com`.
- Keep the filename exactly `index.html` (lowercase).
- `README.md` is documentation, and `.nojekyll` is optional but harmless for this static HTML site.

## Notes

The optical animations are conceptual interactive illustrations, not quantitative simulations of an experimental apparatus. Test the site in a desktop browser after publishing, especially responsive layout and scroll interactions.
